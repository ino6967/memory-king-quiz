# 記憶RPG「メモリア王国」初回プロトタイプ

記憶ボード→王様の設問→正解/不正解のループを実装した最小プロトタイプ。
玉座の間・書庫のドット絵風シーンと、正解/不正解で表情が変わる王様の
キャラクターを Canvas で描画している。ビルド不要のプレーンな
HTML/CSS/JS で構成している。

## 遊び方

```sh
npm start
```

その後ブラウザで `http://localhost:8080/` を開く。

- 「はじめる」を押すと記憶ボードが表示される(STAGE 1は60秒、STAGE 2は90秒)
- 時間切れで自動的に王様の部屋へ移行し、3問の四択問題が出題される
- 正解し続ければステージクリア、1問でも間違えれば即ゲームオーバー
- STAGE 1クリア後は「次のステージへ」でSTAGE 2(現王家+先代王家)に進む。
  STAGE 2までクリアすると「全ステージ制覇!」となる

開発中に60秒待つのが面倒な場合は `http://localhost:8080/?dev=1` を
開くと記憶時間が5秒に短縮される。

## 構成

- `world-db.json` — 正典データベース(唯一の正解ソース)。`people` に
  現王家8人+先代王家2人(先王オズワルド二世・先王妃マグダレーナ)を
  一元管理し、`stages` は各ステージが対象とする人物IDのリスト
  (`peopleIds`)を持つのみで人物データを重複させない。STAGE 1は現王家
  のみ、STAGE 2は先代王家を加えた10人が対象。出題・正解判定は必ず
  このファイルを参照する。
- `world-db.md` — 上記データベースの人間可読な概要と正典ルール。
- `index.html` / `style.css` / `game.js` — ゲーム本体。
- `server.js` — 依存パッケージなしのローカル静的サーバー(`npm start`)。

## 出題ロジック

AIによるその場生成は行わない。`game.js` の `collectCandidates` /
`buildQuestion` が、テンプレート(父・母・配偶者・第一子・身分・
身分から人物を問う逆引き)を `world-db.json` の実データに当てはめて
設問と正解を機械的に生成する。正解判定は常にDBの値を参照するため、
矛盾した問題は出題されない。

## 王様のセリフ

正解・不正解それぞれにセリフのバリエーションを持たせているほか、
`world-db.json` の `kingLines.ominous` は正解時に低頻度(15%)で
混ざる意味深なセリフで、将来のストーリー拡張(どんでん返し)への
伏線として仕込んである。不正解時のセリフは激しめの言い回しを増やし、
王が気の短い性格であることを演出している。正典データ(人物・続柄・
年代)自体は変更していない。

- 入力式の回答(今回は選択式のみ)
